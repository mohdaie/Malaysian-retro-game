# Character source assets

40 full sheets (39 supplied by the user and one Pak Karim sheet generated with built-in image_gen on 9 October 2026) are stored in `assets/characters/`, tagged using the existing game character keys. [manifest.json](../assets/characters/manifest.json) records the original upload filename, printed title and sheet number, actual format, dimensions, SHA-256 checksum, character name, existing NPC ID where present, and home/work place.

Uploaded sheet identities use their printed names. Uploaded copies preserve the source bytes. Although the supplied filenames end in PNG, their encoded image format is JPEG; those registered copies use `<key>-sheet.jpg`. Pak Karim is a newly generated PNG based on his existing game design, with the prompt recorded in [PAK-KARIM-IMAGE-PROMPT.md](PAK-KARIM-IMAGE-PROMPT.md). No re-encoding is performed. The earlier screenshot-derived register has been removed.

## Coverage

All 40 base characters now have a source sheet, including Pak Karim (artwork number 39). Keeper and crowd extras are outside this set.

## Use in the game

All 40 sheets now supply face windows in `src/dialogue-portraits.js`. The source images are unchanged: crop metadata selects the neutral face for each speaker. Additional keeper/crowd speakers use small portraits rendered from their own current game heads, registered in `assets/portraits/game-heads.json`. Printed artwork numbers, `NPC-xx` cast IDs and place numbers are separate identifiers.
